# Papirfly to produkter på en

**[ÅPNE PAPIRFLY-VERKTØYET](https://darschnid479.github.io/Papirflyto/)**

Lag prisplakater fra Papirfly-PDF med to produkter på samme ark. Velg A3, A4 eller A5, skriv egen overskrift, og juster valgfrie innstillinger.

## Publisere nettsiden

Nettsiden er i `index.html` og er laget for GitHub Pages.

Aktiver Pages én gang under [Settings → Pages](https://github.com/Darschnid479/Papirflyto/settings/pages):

1. Under **Build and deployment → Source**, velg **GitHub Actions**.
2. Den ferdige workflowen `.github/workflows/pages.yml` publiserer automatisk fra `main`.
3. Se status under **Actions**.

Deretter åpner **https://darschnid479.github.io/Papirflyto/** selve verktøyet direkte.

> NB: GitHub-adressen `github.com/Darschnid479/Papirflyto` viser alltid repositoryet. GitHub Pages-adressen er nettadressen til selve applikasjonen.
